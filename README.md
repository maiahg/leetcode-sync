# LeetCode → GitHub sync

A Chrome/Chromium Manifest V3 extension that keeps accepted LeetCode solutions
in GitHub with one setup flow.

It supports both:

- Existing accepted submissions through **Sync existing accepted submissions**.
- Future accepted submissions automatically, shortly after LeetCode reports
  **Accepted**.

Every submission keeps its own ID, so different accepted approaches are stored
without overwriting one another:

```text
problems/0001-two-sum/solution-001-python.py
problems/0001-two-sum/solution-002-python.py
```

The default destination layout is:

```text
problems/0001-two-sum/README.md
problems/0001-two-sum/solution-001-python.py
problems/0001-two-sum/solution-002-python.py
.sync/index.json
```

`.sync/index.json` maps each LeetCode submission ID to its GitHub file, so the
extension can resume safely and preserve every accepted approach. It also stores
the last completed history-sync cursor, so later imports only inspect newer
submissions and known submission IDs are skipped.

## Install

1. Install the TypeScript build dependencies and build the extension:

   ```sh
   npm install
   npm run build
   ```

2. Create a fine-grained GitHub token with `Contents: Read and write` access to
   the destination repository.
3. Open `chrome://extensions`, enable **Developer mode**, and choose **Load
   unpacked**.
4. Select the repository's `extension/` folder.
5. Open the extension popup and enter `owner/repository`, the token, branch,
   and optional folder. Leave the folder as `problems` for the layout above.
6. Open any LeetCode problem tab and click **Sync existing accepted
   submissions** once. Keep that tab open until the notification confirms the
   import.
7. Leave the extension installed. Future accepted submissions are captured
   automatically.

The extension reads the code from LeetCode's submitted editor payload, with
Monaco/DOM editor fallbacks. The GitHub token is stored only in Chrome local
extension storage and sent only to `api.github.com`.

Each generated problem README includes the LeetCode title, difficulty, link,
and full problem description. Existing custom READMEs are left untouched; READMEs
generated by this extension are upgraded when the description format changes.

The extension uses GitHub's Contents API and updates one file per accepted
submission. Repeated events for the same submission are skipped locally.

TypeScript sources are in `extension/src/`; Chrome loads the generated files in
`extension/dist/`. Run `npm run build` again after source changes.
